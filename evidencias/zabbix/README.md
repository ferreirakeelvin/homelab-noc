# Evidências do Zabbix

Capturas de tela do laboratório Homelab NOC, realizadas em novembro de 2026.

## Conteúdo

As imagens registram diferentes partes da implementação do monitoramento:

- Dashboard Monitoramento NOC;
- Cadastro dos hosts monitorados;
- Latest data e métricas coletadas;
- Listagens e configurações de triggers.

Os nomes originais preservam a data e o horário de cada captura.

## Segurança e privacidade

- Endereços da rede física foram ocultados.
- URLs internas do frontend Zabbix podem aparecer nas capturas, utilizando endereços privados da rede virtual.
- Endereços da rede virtual do laboratório foram mantidos para contexto técnico.
- Nenhuma credencial foi identificada pela verificação automática por OCR.

A verificação automatizada não substitui a inspeção visual das imagens.
